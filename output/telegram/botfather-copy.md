# Curator Telegram profile

Prepared from the current local Curator web implementation. Live deployment availability was not verified.

## Name

Curator

## About

LP position alerts from Curator. Track range, pool health, PnL changes and rotation signals from your web workspace.

## Welcome message / bot description

See both sides of the pool.

Curator helps liquidity providers compare pools by real fees, depth and risk. Connect this bot to your Curator web account for alerts on:

• Positions out of range or near an edge
• Pool grade deterioration and PnL drops
• Rotation windows opening or closing

To get started, press Start, then add your Telegram chat ID in Curator → Settings and send a test alert.

Read-only analytics. You stay in control.

## Uploads

- Set New Photo: `curator-profile.png` (1024 × 1024).
- Set Welcome Picture: `curator-welcome.png` (640 × 360).
- Default language: English, matching the current website.

The welcome description appears before Start; it does not implement a runtime /start response. Public web users receive configured position alerts; the CLI daemon command interface is restricted to its configured chat ID.
